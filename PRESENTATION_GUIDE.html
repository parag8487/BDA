App name on screen: BehaviorStream  ·  Subject: Big Data Analytics (BDA), Semester 7

1. How to start the project (do this before class)

  1. Open the folder Downloads\Mini Project Sem 7\BDA.
  2. Double-click START-PROJECT.bat. A black window opens. Don't close it while presenting.
  3. The browser opens http://localhost:3000 (if not, type it in yourself).
  4. To stop: close the black window (or press Ctrl + C in it).

Before going to class: start it once at home to make sure it opens. Keep the browser zoom at 100%.

2. The project in one paragraph (memorise this)

"Our project analyses e-commerce customer behaviour using a dual pipeline: a batch pipeline and a real-time streaming pipeline. In the batch pipeline, the customer dataset (380 customers) is stored in Hadoop HDFS and processed with Apache Spark (PySpark) to segment customers, find customers at risk of churn, and train a Logistic Regression model that predicts customer satisfaction. In the streaming pipeline, live purchase events are sent through Apache Kafka and processed by Spark Structured Streaming to detect anomalies like unusually large purchases or very low ratings in real time. Results are stored in PostgreSQL and shown on an interactive web dashboard built in React."

5. Architecture (draw this on the board if asked)

                 BATCH PIPELINE
 CSV dataset ──► HDFS ──► Spark (Analysis.py) ──► PostgreSQL ──┐
                     └──► Spark MLlib (predict.py) ─► model     │
                                                               ├──► React Dashboard
                 STREAMING PIPELINE                             │
 KafkaProducer.py ──► Kafka topic ──► Spark Streaming ──► PostgreSQL / HDFS (Parquet)
                     (3 partitions)   (anomaly + windows)

This is called a Lambda Architecture: a batch layer (accurate, slow, full history) + a speed layer (fast, real-time) + a serving layer (PostgreSQL + dashboard).

7. ⚠️ Be honest about this: it's the most likely tricky question

The web dashboard runs entirely in the browser. It simulates the Hadoop/Spark/Kafka pipeline: the 380 customer records are generated by code, the streaming events are randomly generated every second, the spark-submit logs are scripted, and the SQL console recognises the preset queries (it is not a real PostgreSQL connection). The real cluster code (docker-compose + 4 Python scripts) is included in the Cluster Architecture tab, but it is not running on this laptop.

If the teacher asks "Is Hadoop actually running?", say:

"The dashboard is the presentation/visualisation layer and simulates the pipeline so it can be demonstrated on a laptop without a cluster. The real implementation (docker-compose for Hadoop, Spark, Kafka and PostgreSQL, plus the PySpark and Kafka scripts) is shown in the Cluster Architecture tab and can be run with docker-compose up -d. Running the full cluster needs about 8–16 GB RAM, so for the demo we used the simulated dashboard."

Don't claim it is connected live to Hadoop. Teachers usually respect an honest answer and penalise a bluff.

8. Likely viva questions & answers

Click a question to see the answer. Try answering it yourself first.

Big Data basics

What is Big Data? What are the 5 V's?

Data too large/fast/varied for traditional systems. Volume (size), Velocity (speed of arrival), Variety (types: structured, semi-, unstructured), Veracity (accuracy/quality), Value (useful insight).
In our project: Velocity = Kafka streaming, Volume = HDFS storage, Value = churn & satisfaction insights.

Batch vs. stream processing?

Batch = process a large stored dataset at once (e.g. daily report): high latency, complete view. Stream = process each event as it arrives: low latency (milliseconds/seconds). We use both.

What is Lambda Architecture?

Batch layer + speed (streaming) layer + serving layer. Our project follows it.

Hadoop

What is HDFS?

Hadoop Distributed File System. Splits files into blocks (128 MB default) and stores them across DataNodes with replication (default 3; we use 1 since it's a single-node demo).

NameNode vs DataNode?

NameNode = master, stores metadata (which block is where). DataNode = worker, stores the actual blocks.

What is YARN?

Yet Another Resource Negotiator: Hadoop's resource manager. ResourceManager (master) + NodeManager (per node).

Command to upload a file to HDFS?

hdfs dfs -put localfile /hdfs/path

Web UI ports?

NameNode UI 9870, YARN 8088, Spark Master 8080.

Spark

Why Spark instead of MapReduce?

Spark processes data in memory; MapReduce writes to disk between every step. Spark also has SQL, MLlib and Streaming in one engine.

What is an RDD / DataFrame?

RDD = Resilient Distributed Dataset, Spark's basic immutable distributed collection. DataFrame = RDD with named columns (like a table). We use DataFrames.

Transformation vs Action?

Transformations (filter, groupBy, withColumn) are lazy: nothing runs. Actions (count, show, write) trigger execution.

What is lazy evaluation?

Spark builds a plan (DAG) and only executes when an action is called, which lets it optimise.

What is the DAG?

Directed Acyclic Graph of stages that Spark builds for a job.

Driver vs Executor?

The driver runs your main program and plans the job; executors run the tasks on worker nodes.

What does spark-submit do?

Submits a PySpark script to the cluster (--master yarn).

Spark MLlib / Machine Learning (Q3)

Why Logistic Regression?

Simple, fast, interpretable (we can see each feature's weight), and works for classification. We used the multinomial version because there are 3 classes.

What is the sigmoid / softmax?

Sigmoid maps any number to 0–1 (a probability). Softmax is the multi-class version.

Steps in your ML pipeline?
  1. StringIndexer: converts text categories (Gender, City, Membership, label) to numbers
  2. OneHotEncoder: turns category indexes into 0/1 vectors
  3. VectorAssembler: combines all features into one vector
  4. StandardScaler: scales features so none dominates
  5. LogisticRegression (maxIter=100, regParam=0.01, elasticNet=0.2)
Features used?

Age, Total Spend, Items Purchased, Average Rating, Days Since Last Purchase, Gender, City, Membership Type. Target: Satisfaction Level.

Train/test split?

80% train / 20% test, seed=42 so it's reproducible.

Accuracy vs F1-score?

Accuracy = correct predictions / total. F1 = harmonic mean of precision and recall, which is better when classes are unbalanced.

Precision vs Recall?

Precision = of the ones predicted positive, how many were right. Recall = of the actual positives, how many we found.

Confusion matrix?

A table of actual vs predicted classes. The diagonal is the correct predictions.

What is regularisation?

A penalty on large weights to avoid overfitting. ElasticNet mixes L1 (Lasso) and L2 (Ridge).

Most important feature?

Average Rating (+1.25), then Gold membership (+0.85). Days since last purchase is negative (−0.058).

Segmentation & Churn (Q1, Q2)

What is churn?

When a customer stops buying from the company.

How do you calculate churn risk?

Based on days since last purchase (more days → more risk) and satisfaction (unsatisfied → +35, neutral → +15, satisfied → −10), Gold members −10, low rating +15. Capped at 5–99.

Why 45 days?

A business threshold for "inactive". It can be tuned (the threshold buttons show that).

How did you segment customers?

The dashboard labels 5 segments using business rules on spend, membership, items, discount use and churn score (e.g. spend > $2,500 and Gold → VIP). If asked about K-Means: the screen title says K-Means; be honest that the dashboard segments are rule-based, and K-Means (unsupervised clustering into k groups by distance to centroids) is the algorithm that would be used on the real cluster.

Kafka & Streaming

What is Kafka?

A distributed publish–subscribe messaging system. Producers write messages to topics, consumers read them.

Topic, partition, offset?

Topic = named stream (ecommerce.transactions.v1). Partition = a topic is split into parts for parallelism (we have 3). Offset = position number of a message in a partition (shown as p1:10419).

Consumer group?

A set of consumers that share partitions so each message is processed once by the group.

Why Zookeeper?

Manages Kafka broker metadata and leader election (newer Kafka can use KRaft instead).

What is a sliding window?

Aggregation over the last 30 seconds, recalculated every 10 seconds.

What is a watermark?

How long Spark waits for late-arriving data (1 minute here) before finalising a window.

How are anomalies detected?

Rules: amount > $1,500 or rating ≤ 1.5.

What is a micro-batch?

Spark Structured Streaming processes the stream in tiny batches every few milliseconds/seconds.

PostgreSQL

Why PostgreSQL if you already have HDFS?

HDFS is for large raw data; PostgreSQL stores the small final results that dashboards query quickly with SQL.

How does Spark write to PostgreSQL?

Through JDBC: .write.format("jdbc").option("url", "jdbc:postgresql://postgres:5432/ecommerce_analytics").

Docker

What is Docker?

It packages software into containers that run the same everywhere. docker-compose starts many containers (Hadoop, Spark, Kafka, Postgres) from one YAML file.

Project-level

Dataset?

E-commerce Customer Behavior dataset, 380 customers. Columns: Customer ID, Gender, Age, City, Membership Type, Total Spend, Items Purchased, Average Rating, Discount Applied, Days Since Last Purchase, Satisfaction Level. (In the dashboard the 380 records are generated by code that mimics this dataset.)

Limitations?

Small dataset (380 rows, not truly "big"); the dashboard is a simulation; churn rules are hand-made thresholds; single-node cluster (replication = 1).

Future scope?

Run on a real multi-node cluster or the cloud (AWS EMR / Databricks); use larger real datasets; try Random Forest / XGBoost; real-time dashboards with Grafana; a recommendation system; automatic win-back emails.

Real-world applications?

Amazon/Flipkart customer retention, fraud detection in payments, personalised offers, inventory planning.
